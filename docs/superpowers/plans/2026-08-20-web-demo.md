# @unitrack/web-demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@unitrack/web-demo` — a browser-only host app proving `@unitrack/core` plus `any`/`web`-tier plugins run with zero Node APIs, served as plain static files via a generated import map (no bundler) — as specified in `docs/superpowers/specs/2026-08-20-web-demo-design.md`.

**Architecture:** `server.js` (Node, `node:http`) walks `node_modules/@unitrack/*`, builds a browser import map from each package's own `package.json.exports`, and serves it inlined into `index.html` alongside static files. `main.js` (browser ES module) constructs a `CorePlayer`, wires connection forms for `@unitrack/source-subsonic`/`@unitrack/source-s3` and an "Add Track" form (primary + optional fallback source) to it, and reuses `@unitrack/electron-demo`'s established `core.on(...)` → DOM-update wiring pattern.

**Tech Stack:** Plain JavaScript (ESM), JSDoc types checked via `tsc --checkJs --strict` (combined Node+DOM `lib`, matching `@unitrack/electron-demo`'s own tsconfig). No test framework dependency; a manual/best-effort Playwright smoke test (not part of `npm test`, not wired into CI) is Task 4's own verification step.

## Global Constraints

- No bundler, no build step — `server.js` only ever serves existing `.js` files verbatim plus a generated import map; nothing is transpiled or concatenated.
- Only `any`/`web`-tier plugins: `@unitrack/source-subsonic`, `@unitrack/source-s3`, `@unitrack/engine-audio-queue`. No `desktop`-tier plugin is ever imported.
- Credentials from the connection forms live only in an in-memory closure — never written to `localStorage`, a cookie, or any file.
- Out of scope per spec Non-goals: service worker/offline, credential persistence, drag-reorder/shuffle/repeat/folder-scan UI, `nowPlaying` integration, real deployment.
- `npm run typecheck`, run from the repo root, must pass cleanly (delegating into this new workspace package too) at the end of the task. This app has no `npm test` script — matching `@unitrack/electron-demo`'s own precedent of shipping zero automated tests for a manual-verification-only app.

- [ ] **Step 4: `server.js`**

```js
import { createServer } from 'node:http';
import { readFile, readdir } from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const REPO_ROOT = path.resolve(__dirname, '../..');
const PORT = Number(process.env.PORT ?? 8080);

const MIME_TYPES = {
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.mjs': 'text/javascript; charset=utf-8',
  '.json': 'application/json; charset=utf-8',
};

/**
 * Builds a browser import map from every workspace package's own
 * package.json.exports — the same data Node's own resolver reads, so this
 * can never silently drift from what Node considers each package's public
 * surface. See design spec's "Server" section.
 * @returns {Promise<Record<string, string>>}
 */
async function buildImportMap() {
  const unitrackDir = path.join(REPO_ROOT, 'node_modules', '@unitrack');
  const entries = await readdir(unitrackDir, { withFileTypes: true });
  /** @type {Record<string, string>} */
  const imports = {};
  for (const entry of entries) {
    if (!entry.isDirectory() && !entry.isSymbolicLink()) continue;
    const pkgJsonPath = path.join(unitrackDir, entry.name, 'package.json');
    /** @type {{ name: string, exports?: Record<string, { import?: string }> }} */
    const pkg = JSON.parse(await readFile(pkgJsonPath, 'utf8'));
    for (const [exportKey, condition] of Object.entries(pkg.exports ?? {})) {
      if (!condition.import) continue;
      const specifier = exportKey === '.' ? pkg.name : `${pkg.name}/${exportKey.slice(2)}`;
      const target = `/node_modules/@unitrack/${entry.name}/${condition.import.replace(/^\.\//, '')}`;
      imports[specifier] = target;
    }
  }
  return imports;
}

/** @param {string} filePath @returns {Promise<Buffer | null>} */
async function safeReadFile(filePath) {
  try {
    return await readFile(filePath);
  } catch {
    return null;
  }
}

const server = createServer(async (req, res) => {
  const url = new URL(req.url ?? '/', `http://localhost:${PORT}`);

  if (url.pathname === '/') {
    const template = await readFile(path.join(__dirname, 'index.template.html'), 'utf8');
    const importMap = await buildImportMap();
    const html = template.replace('%%IMPORT_MAP%%', JSON.stringify({ imports: importMap }, null, 2));
    res.writeHead(200, { 'Content-Type': MIME_TYPES['.html'] });
    res.end(html);
    return;
  }

  // Serve this app's own files, or anything under the repo root's
  // node_modules (which resolves the import map's target URLs above —
  // node_modules/@unitrack/<pkg> is a workspace symlink into
  // packages/<tier>/<pkg>, so this also transparently serves each
  // package's real source file, not a copy).
  const relativePath = decodeURIComponent(url.pathname).replace(/^\//, '');
  const candidatePaths = [
    path.join(__dirname, relativePath),
    path.join(REPO_ROOT, relativePath),
  ];
  for (const candidate of candidatePaths) {
    if (!candidate.startsWith(REPO_ROOT)) continue; // no path traversal above the repo root
    const body = await safeReadFile(candidate);
    if (body) {
      const ext = path.extname(candidate);
      res.writeHead(200, { 'Content-Type': MIME_TYPES[ext] ?? 'application/octet-stream' });
      res.end(body);
      return;
    }
  }
  res.writeHead(404);
  res.end('not found');
});

server.listen(PORT, () => {
  console.log(`@unitrack/web-demo listening on http://localhost:${PORT}`);
});
```

- [ ] **Step 7: `main.js`**

Construct `core = new CorePlayer()`, register `createAudioQueuePlaybackEngine()` immediately (no config needed). Do **not** register either source provider immediately — wait for a connection form submit (see spec's Interface section). After each provider registration, re-run `core.initializePlugins({ log, config: {}, host: { platform: 'web', version: navigator.userAgent } })` (idempotent per plugin — `PluginRegistry`/`CorePlayer` already tolerate re-initialization the same way `@unitrack/electron-demo` never worries about calling it more than once, since it only ever calls it exactly once — confirm this assumption against `CorePlayer.initializePlugins()`'s actual implementation in Step 7's own execution; if double-initialization of an already-initialized plugin throws, only call it once per newly-registered plugin instead of once globally).

Set an initial policy covering both source kinds once at least one is registered: `core.setPolicy([{ kind: 'self-hosted' }, { kind: 'object-storage' }])` (order = primary-first if the user's "Add Track" form always puts the fallback source second in `LogicalTrack.sources`, matching how `Resolver.js`'s policy iterates).

"Add Track" form submit handler builds:
```js
const sources = [{ pluginId: primaryPluginId, token: { pluginId: primaryPluginId, token: primaryKey }, kind: primaryKind }];
if (fallbackKey) sources.push({ pluginId: fallbackPluginId, token: { pluginId: fallbackPluginId, token: fallbackKey }, kind: fallbackKind });
await core.enqueue({ id: crypto.randomUUID(), metadata: { artist: '', album: '', title }, sources });
```

Reuse (adapted, not reinvented) `@unitrack/electron-demo/preload.mjs`'s: `requireElement`/`requireInputElement`, `formatTime`, `updateStatus`/`renderQueue`/`updateSeek`, the `core.on(...)` block, and the transport-button wiring loop. Drop: `mapWithConcurrencyLimit` (no folder scan here), `autoPlayIfEnabled`/`config.autoPlayOnOpen` (no config.json in this app), shuffle/repeat wiring, the queue row's ▲/▼/✕ buttons (read-only list per spec — keep only click-to-jump).

Logging: plain `console.log(scope, message, detail)` — no IPC, no synchronous main-process channel (there is no main process). Simpler than `@unitrack/electron-demo`'s logging by necessity, not by omission.
