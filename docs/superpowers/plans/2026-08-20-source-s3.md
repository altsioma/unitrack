# @unitrack/source-s3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@unitrack/source-s3` — a `SourceProvider` plugin for `@unitrack/core` that resolves a `SourceRef` pointing at an object key in an S3-compatible bucket into a presigned-URL `ResolvedSource`, `HEAD`-checking the object first so a bad key/credential/deleted-bucket fails visibly during resolution — as specified in `docs/superpowers/specs/2026-08-20-source-s3-design.md`.

**Architecture:** A single new npm workspace package, `packages/plugins/any/source-s3/`, exporting one factory function, `createS3SourceProvider(config)`, plus an internally-reusable `presignGetUrl()` from a separate `sigv4.js` module. No runtime dependency on `@unitrack/core` (devDependency only). AWS Signature Version 4 query-string presigning implemented from scratch against `globalThis.crypto.subtle` (`SHA-256`/`HMAC-SHA256` only — both are standard `SubtleCrypto` algorithms, no hand-rolled crypto needed here unlike `source-subsonic`'s MD5). `fetch`/`AbortController` are real Node globals, not injected.

**Tech Stack:** Plain JavaScript (ESM) with JSDoc types checked via `tsc --checkJs --strict`. Tests via `node:test` + `node:assert/strict`, against a real `node:http` server standing in for an S3-compatible endpoint (no mocking library) plus pure unit tests for `sigv4.js` cross-checked against AWS's own published worked example and independent `node:crypto` recomputation. Zero runtime dependencies.

## Global Constraints

- Zero runtime dependencies. `@unitrack/core`, `@unitrack/conformance-kit`, `@types/node`, and `typescript` are devDependencies only.
- Presigning is query-string-style SigV4 only (no header-based `Authorization` signing) — see spec's Protocol section for why.
- `resolve()`/`revalidate()` always perform a live `HEAD` against the presigned URL — no connectivity caching across calls, matching `source-subsonic`'s same posture.
- `now` is always an explicit parameter to `presignGetUrl()`, never read internally from `Date.now()` — required for reproducible, fixture-testable signatures.
- Out of scope for this plan (per spec Non-goals): bucket listing/browsing, object metadata/tag fetching, any write path (`PutObject`, delete, multipart upload), an SDK-style credential provider chain, range-request optimization, XML error-body parsing (HEAD responses have no body).
- `npm run typecheck` and `npm test`, run from the repo root, must both pass cleanly (delegating into every workspace package, including this new one) at the end of the task.

- [ ] **Step 2: Write the `UriEncode` helper and canonical-request builder**

`packages/plugins/any/source-s3/src/sigv4.js` — internal (non-exported) helpers:

```js
/**
 * SigV4's UriEncode: RFC 3986 unreserved characters (A-Z a-z 0-9 - _ . ~)
 * pass through; everything else is percent-encoded, uppercase hex.
 * encodeURIComponent already does most of this but deliberately leaves
 * `! ' ( ) *` unescaped — SigV4 requires those encoded too.
 * @param {string} value
 * @returns {string}
 */
function uriEncode(value) {
  return encodeURIComponent(value).replace(/[!'()*]/g, (c) => `%${c.charCodeAt(0).toString(16).toUpperCase()}`);
}

/**
 * Canonical URI: each path segment UriEncode'd, `/` separators preserved.
 * @param {string} key
 * @returns {string}
 */
function canonicalUri(key) {
  return '/' + key.split('/').map(uriEncode).join('/');
}

/**
 * @param {Record<string, string>} params
 * @returns {string}
 */
function canonicalQueryString(params) {
  return Object.keys(params).sort()
    .map((k) => `${uriEncode(k)}=${uriEncode(params[k])}`)
    .join('&');
}
```

- [ ] **Step 3: Write the SHA-256/HMAC-SHA256 `crypto.subtle` wrappers**

```js
/**
 * @param {string} message
 * @returns {Promise<string>} lowercase hex SHA-256 digest
 */
async function sha256Hex(message) {
  const digest = await globalThis.crypto.subtle.digest('SHA-256', new TextEncoder().encode(message));
  return Array.from(new Uint8Array(digest)).map((b) => b.toString(16).padStart(2, '0')).join('');
}

/**
 * @param {Uint8Array | string} key
 * @param {string} message
 * @returns {Promise<Uint8Array>}
 */
async function hmacSha256(key, message) {
  const keyBytes = typeof key === 'string' ? new TextEncoder().encode(key) : key;
  const cryptoKey = await globalThis.crypto.subtle.importKey(
    'raw', keyBytes, { name: 'HMAC', hash: 'SHA-256' }, false, ['sign']
  );
  const signature = await globalThis.crypto.subtle.sign('HMAC', cryptoKey, new TextEncoder().encode(message));
  return new Uint8Array(signature);
}
```

2. A key with a space and a `+` (e.g. `'music/a b+c.flac'`) — assert the resulting URL's path/query encode them per `UriEncode` (space → `%20`, not `+`; `+` → `%2B`), and independently recompute the expected signature in the test via `node:crypto`'s `createHmac('sha256', ...)` chain (not by calling `sigv4.js`'s own helpers) to catch a bug the production code and a same-implementation test would share.
3. `forcePathStyle: true` produces `{endpoint}/{bucket}/{key}` with `Host: {endpointHost}`; `forcePathStyle: false` produces `{scheme}://{bucket}.{endpointHost}/{key}` with `Host: {bucket}.{endpointHost}` — both against the same key/credentials, asserting the URL shape and that the signature changes consistently with the `Host` used (i.e. the path-style URL's signature must NOT equal the virtual-hosted URL's signature, proving `Host` genuinely participates in signing).
4. `sessionToken`, when passed, appears as `X-Amz-Security-Token` in the query string; `X-Amz-SignedHeaders` stays `host` (unaffected).

- [ ] **Step 5: Run to verify failure, then implement `presignGetUrl()`**

```js
/**
 * @param {{
 *   endpoint: string, region: string, bucket: string, key: string,
 *   accessKeyId: string, secretAccessKey: string, sessionToken?: string,
 *   forcePathStyle: boolean, expiresInSeconds: number, now: Date,
 * }} params
 * @returns {Promise<string>}
 */
export async function presignGetUrl({
  endpoint, region, bucket, key, accessKeyId, secretAccessKey, sessionToken,
  forcePathStyle, expiresInSeconds, now,
}) {
  const endpointUrl = new URL(endpoint);
  const host = forcePathStyle ? endpointUrl.host : `${bucket}.${endpointUrl.host}`;
  const path = forcePathStyle ? canonicalUri(`${bucket}/${key}`) : canonicalUri(key);

  const amzDate = now.toISOString().replace(/[:-]|\.\d{3}/g, ''); // YYYYMMDDTHHMMSSZ
  const dateStamp = amzDate.slice(0, 8);
  const credentialScope = `${dateStamp}/${region}/s3/aws4_request`;

  /** @type {Record<string, string>} */
  const queryParams = {
    'X-Amz-Algorithm': 'AWS4-HMAC-SHA256',
    'X-Amz-Credential': `${accessKeyId}/${credentialScope}`,
    'X-Amz-Date': amzDate,
    'X-Amz-Expires': String(expiresInSeconds),
    'X-Amz-SignedHeaders': 'host',
  };
  if (sessionToken) queryParams['X-Amz-Security-Token'] = sessionToken;

  const canonicalQs = canonicalQueryString(queryParams);
  const canonicalRequest = [
    'GET', path, canonicalQs, `host:${host}\n`, 'host', 'UNSIGNED-PAYLOAD',
  ].join('\n');

  const stringToSign = [
    'AWS4-HMAC-SHA256', amzDate, credentialScope, await sha256Hex(canonicalRequest),
  ].join('\n');

  const kDate = await hmacSha256(`AWS4${secretAccessKey}`, dateStamp);
  const kRegion = await hmacSha256(kDate, region);
  const kService = await hmacSha256(kRegion, 's3');
  const kSigning = await hmacSha256(kService, 'aws4_request');
  const signatureBytes = await hmacSha256(kSigning, stringToSign);
  const signature = Array.from(signatureBytes).map((b) => b.toString(16).padStart(2, '0')).join('');

  const scheme = endpointUrl.protocol.replace(':', '');
  return `${scheme}://${host}${path}?${canonicalQs}&X-Amz-Signature=${signature}`;
}
```

- [ ] **Step 9: Implement `createS3SourceProvider`**

`packages/plugins/any/source-s3/src/index.js`:

```js
import { CONTRACT_VERSION } from '@unitrack/core/types';
import { presignGetUrl } from './sigv4.js';

/**
 * @param {{
 *   endpoint: string, region: string, bucket: string,
 *   accessKeyId: string, secretAccessKey: string, sessionToken?: string,
 *   id?: string, forcePathStyle?: boolean, expiresInSeconds?: number,
 *   timeoutMs?: number,
 * }} config
 * @returns {import('@unitrack/core/types').SourceProvider}
 */
export function createS3SourceProvider({
  endpoint, region, bucket, accessKeyId, secretAccessKey, sessionToken,
  id = 's3', forcePathStyle = true, expiresInSeconds = 300, timeoutMs = 5000,
}) {
  /**
   * @param {string} key
   * @returns {Promise<{ url: string, contentType: string }>}
   */
  async function headObject(key) {
    const url = await presignGetUrl({
      endpoint, region, bucket, key, accessKeyId, secretAccessKey, sessionToken,
      forcePathStyle, expiresInSeconds, now: new Date(),
    });
    const controller = new AbortController();
    const timeout = setTimeout(() => controller.abort(), timeoutMs);
    /** @type {Response} */
    let response;
    try {
      response = await fetch(url, { method: 'HEAD', signal: controller.signal });
    } finally {
      clearTimeout(timeout);
    }
    if (response.status === 403) throw new Error('s3 object access denied (check credentials or expired signature)');
    if (response.status === 404) throw new Error('s3 object not found');
    if (!response.ok) throw new Error(`s3 head failed: HTTP ${response.status}`);
    return { url, contentType: response.headers.get('content-type') ?? 'application/octet-stream' };
  }

  return {
    id,
    kind: 'object-storage',
    contractVersion: CONTRACT_VERSION,
    capabilities: { offline: false, requiresRevalidation: true },
    async initialize(ctx) {},
    async dispose() {},
    /** @param {import('@unitrack/core/types').SourceRef} ref */
    async canResolve(ref) {
      return ref.pluginId === id;
    },
    /** @param {import('@unitrack/core/types').SourceRef} ref */
    async resolve(ref) {
      const { url, contentType } = await headObject(ref.token.token);
      return { kind: 'url', url, mime: contentType };
    },
    /** @param {import('@unitrack/core/types').SourceToken} token */
    async revalidate(token) {
      try {
        await headObject(token.token);
        return { valid: true, token };
      } catch (err) {
        return { valid: false, reason: err instanceof Error ? err.message : String(err) };
      }
    },
  };
}
```

Note the `pluginId === token.pluginId` invariant (see `types.js`'s `SourceRef` doc comment, enforced by `Resolver.resolveTrack()` for every ref that flows through Core) — this provider itself never needs to check it (only `Resolver.js` does, before calling any provider method), matching `source-subsonic`'s own posture.
